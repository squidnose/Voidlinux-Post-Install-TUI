### Basic Setup
- Grub-Kernel-Parameters |  [[More info]](https://github.com/squidnose/Voidlinux-Post-Install-TUI/blob/main/scripts/1.Basic-Setup/Grub-Kernel-Parameters/0.info.md)
- Power-Managment | Setup power managemnt SW. Handy for laptops. 
- HW-clock-For-Windows-Dualboot.sh | Sets the internal clock to use the HW clock (For Windows DualBoot)
- HW-detection.sh | Detects your Current CPU, GPU and Network card in order to reccomend certin drivers or optimizatoins.
- repos.sh | Manage these reposoitories: nonfree, 32-bit, nonfree-32bit and Flathub. Important for Steam and Flatpak applications aswell and Nvidia and Broadcom users.
- Services-Runit.sh | Manage runit services
- UserGroups.sh | Add the curent user to thees groups: wheel,floppy,dialout,audio,video,cdrom,optical,kvm,users,xbuilder,network
- Voidlinux-Kernel-Manager.sh | Add or remove any kernel version avaliable in the Repos
